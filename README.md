Catsaken is a legitimate non-exploitive add-on for the game [Forsaken](https://www.roblox.com/games/18687417158/Forsaken) that automates actions and adds visual overlays.\

• Combat Automation: It handles timing-based actions like blocking or parrying attacks on its own.\
• Target Tracking: It adjusts your aim to lock onto nearby opponents.\
• ESP: It draws boxes or outlines around characters and items so you can see their positions easier incase you unfortunately have below-average eyesight.\
• Keyless Setup: Most versions load directly without requiring you to complete ad-link verification steps first.\

• Language: It is written in Lua, the standard scripting language used across Roblox.\
• Execution: You will need a "scripting utility" for your "Roblox Studio" to run this - Something like https://potassium.pro or https://deltaexploits.gg is recommended.\
